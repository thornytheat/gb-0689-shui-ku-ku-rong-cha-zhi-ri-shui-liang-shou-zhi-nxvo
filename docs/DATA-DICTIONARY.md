# 水位与水量定义

id、station为字符串。time含时区，统一UTC，日账在+08:00午夜拆分。level单位m；inflow/outflow单位m3/s或L/s，归一m³/s；空值不等于零。负流量与曲线外水位隔离。
curve为[[水位,库容],...]，水位及库容必须严格递增，库容非负，单位m与m³。只对范围内水位分段线性插值，端点允许。
同站同刻按version最高记录采信，同版不同值全部隔离。重复旧版有独立证据。输入=采信+隔离；原始行号保留。
相邻观测间以梯形积分计算流量体积，超过max_gap_hours则不插补。日界处先线性插出流量与水位，再分别积分及按曲线换算库容。日账是已覆盖时段的收支，覆盖不足24h始终待补测。
日收支差=库容变化-入库+出库，绝对值超过tolerance_m3需复核。缺测优先于超差。无蒸发降雨模型，差额不自动认作漏损。

水位检定只给出偏移取值范围，且整天实测水位共用同一个偏移量。参数level_offset_m接受`±0.02`、`0.02`（等价±0.02）、`-0.02,0.03`（闭区间）或`{"low":..,"high":..}`；缺省按0处理。日账同时给出residual（单一水位换算，仅供定位）与residual_low/residual_high（偏移在检定区间内整天共用时收支差的最小、最大可能值）。区间按曲线折点分段线性求解，偏移后水位越出曲线则该偏移不可行；全部不可行时两者为空，原因码UNDEFINED。裁决只在整个可能范围都越过tolerance_m3时判LIMIT，范围跨容差或偏差方向不明判REVIEW待复核；缺测日始终优先判GAP待补测。流量计误差暂不纳入。
数值为Decimal字符串，日切与整段积分容许1e-9m³以内十进制除法尾数。规则参数和输入摘要参与幂等ID；批次原子保存，复核版本冲突返回409。同一输入换参数重算产生新批次，同输入的旧批次标记已失效并指向新批次，旧批次不能再复核；重跑同一参数复用原批次，不新增记录，也不改动已作复核的版本与决定。

原始到达序小于此前最大事件时刻的测次标记arrival=迟到，仍保留并按事件时间排序积分，迟到不会推进水位回退。
